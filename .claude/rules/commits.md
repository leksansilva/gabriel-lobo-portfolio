# Commit Messages

Emoji-prefixed commits following [iuricode/padroes-de-commits](https://github.com/iuricode/padroes-de-commits).

## Format

```
<:emoji-shortcode:> <short description>
```

- Shortcode text form (`:sparkles:`), not the unicode emoji.
- Description concise and imperative, in English, lowercase start (`:sparkles: add projects section`).
- The harness appends the `Co-Authored-By` trailer; the emoji format applies to the subject line.

## Choosing the emoji

| Emoji code           | Use for                       |
| -------------------- | ----------------------------- |
| `:tada:`             | Initial commit / project init |
| `:sparkles:`         | New feature                   |
| `:bug:`              | Bug fix                       |
| `:recycle:`          | Refactoring                   |
| `:zap:`              | Performance                   |
| `:lipstick:`         | UI styling                    |
| `:iphone:`           | Responsiveness                |
| `:wheelchair:`       | Accessibility                 |
| `:test_tube:`        | Creating/modifying tests      |
| `:white_check_mark:` | Adding tests                  |
| `:books:`            | Documentation                 |
| `:pencil:`           | Text / copy updates           |
| `:wrench:`           | Configuration                 |
| `:bricks:`           | CI / infrastructure           |
| `:rocket:`           | Deploy                        |
| `:package:`          | package.json / dependencies   |
| `:heavy_plus_sign:`  | Add dependency                |
| `:heavy_minus_sign:` | Remove dependency             |
| `:truck:`            | Move / rename files           |
| `:broom:`            | Cleanup                       |
| `:wastebasket:`      | Delete files                  |
| `:boom:`             | Revert                        |
| `:lock:`             | Security                      |
| `:mag:`              | SEO                           |
| `:bookmark:`         | Version / release tag         |
| `:label:`            | Types                         |
| `:goal_net:`         | Error handling                |
| `:card_file_box:`    | Data / config files           |
| `:ok_hand:`          | Code review adjustments       |
| `:dizzy:`            | Animations / transitions      |
| `:construction:`     | Work in progress              |

## Examples

```
:tada: initial commit
:sparkles: add hero section
:lipstick: adjust header spacing on mobile
:mag: add open graph metadata
:dizzy: animate project cards on scroll
```
